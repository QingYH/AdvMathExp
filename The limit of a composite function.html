复合函数极限运算法则

去心邻域有定义 · 内外联动 · 反例解读

法则陈述

设 $\displaystyle\lim_{x\to x_0} g(x)=u_0$， 且存在 $\delta_0>0$，使当 $0<|x-x_0|<\delta_0$ 时：

(i) $f(g(x))$ 有定义，即 $x\in D_g$ 且 $g(x)\in D_f$；
(ii) $g(x)\neq u_0$。

若 $\displaystyle\lim_{u\to u_0} f(u)=L$，则

$$\lim_{x\to x_0} f\big(g(x)\big)=\lim_{u\to u_0} f(u)=L$$

特别地，若外函数 $f$ 在 $u_0$ 处连续，条件 (ii) 自动可去， 但条件 (i) 仍不可省：

$$\lim_{x\to x_0} f\big(g(x)\big)=f\Big(\lim_{x\to x_0} g(x)\Big)=f(u_0)$$

直觉：$x\to x_0$ ⟹ 中间变量 $u=g(x)\to u_0$ ⟹ 外层值 $f(u)\to L$。 但前提是复合函数在 $x_0$ 的某个去心邻域内有定义， 否则极限的定义式 $\forall\varepsilon>0,\exists\delta>0,\ldots$ 中的 $|f(g(x))-L|<\varepsilon$ 根本无从写起。

复合函数的定义域与去心邻域

设 $y=f(u)$，$u=g(x)$，复合函数 $y=f(g(x))$ 的定义域为

$$D_{f\circ g}=\{\,x\in D_g \;\big|\; g(x)\in D_f\,\}$$

考察 $\displaystyle\lim_{x\to x_0} f(g(x))$ 时，极限定义要求 $x_0$ 的某个去心邻域整体包含在 $D_{f\circ g}$ 中。 这正是法则陈述中条件 (i) 的含义：

去心邻域条件 (i)：存在 $\delta_1>0$，使当 $0<|x-x_0|<\delta_1$ 时，
    $x\in D_g$ 且 $g(x)\in D_f$，
即 $x_0$ 的某个去心邻域整体包含在 $D_{f\circ g}$ 中。

为什么强调“整体包含”而不只是“聚点”？因为极限定义里的 $0<|x-x_0|<\delta$ 是对邻域内每一个点都要求 $|f(g(x))-L|<\varepsilon$ 有意义。 如果邻域里有无定义的点，那么这句话对这些点根本没有真假可言，极限也就无从谈起。

三种典型情形对比

  • 良态 $x_0$ 是 $D_g$ 的聚点，$u_0$ 是 $D_f$ 的聚点， 且 $g$ 在 $x_0$ 附近的值域落于 $D_f$ 内 → 去心邻域存在，法则可用。 （案例 A）
  • 全无定义 $x_0$ 是 $D_g$ 的聚点，$u_0$ 是 $D_f$ 的聚点，内层极限也存在， 但 $x\neq x_0$ 时 $g(x)$ 全都落在 $D_f$ 之外 → 不存在任何去心邻域使复合函数有定义。 （案例 B）
  • 振荡破坏 $x_0$ 是 $D_g$ 的聚点，$u_0$ 是 $D_f$ 的聚点，内层极限也存在， 但 $g(x)$ 在 $x_0$ 附近无限次取到 $u_0$，而 $u_0\notin D_f$ → 去心邻域内有无定义点，复合函数极限不存在。 （案例 C）
案例 B 的具体数据：$g(x)=-x^2$，$D_g=\mathbb{R}$，$x_0=0$，$u_0=0$； $f(u)=\sqrt{u}$，$D_f=[0,+\infty)$。
• $\displaystyle\lim_{x\to0}g(x)=0$ ✓
• $\displaystyle\lim_{u\to0}f(u)=0$ ✓
• 但 $x\neq0$ 时 $g(x)=-x^2<0\notin D_f$，复合函数 $\sqrt{-x^2}$ 在 $x=0$ 的任何去心邻域内都无定义 ✗
所以 $\displaystyle\lim_{x\to0}f(g(x))$ 不存在（无意义）。
案例 C 的具体数据（图片案例）：$g(x)=x^2\sin\dfrac{1}{x}$，$D_g=\mathbb{R}$，$x_0=0$，$u_0=0$； $f(u)=\dfrac{\sin u}{u}$，$D_f=\mathbb{R}\setminus\{0\}$。
• $\displaystyle\lim_{x\to0}g(x)=0$ ✓
• $\displaystyle\lim_{u\to0}f(u)=1$ ✓
• 当 $x=\dfrac{1}{n\pi}$ 或 $-\dfrac{1}{n\pi}$（$n\in\mathbb{Z}\setminus\{0\}$）时， $g(x)=0\notin D_f$，复合函数 $f(g(x))$ 无定义。
• 这些点 $x=\pm\dfrac{1}{n\pi}$ 在 $x_0=0$ 附近无限稠密，所以 $x_0=0$ 的任何去心邻域内都包含无定义点 ✗
所以 $\displaystyle\lim_{x\to0}f(g(x))$ 不存在（无意义）。

条件 (i) 与 (ii) 是两个独立的坑： (i) 保证复合函数有定义，(ii) 保证复合过程真正取到外函数去心极限的行为。 两条都满足，运算法则才成立。

三条适用前提

  • 内层 $\displaystyle\lim_{x\to x_0}g(x)=u_0$ 存在（有限）。
  • 外层 $\displaystyle\lim_{u\to u_0}f(u)=L$ 存在（有限）。
  • 邻域 存在 $\delta_0>0$，使 $0<|x-x_0|<\delta_0$ 时， (i) $f(g(x))$ 有定义；(ii) $g(x)\neq u_0$。 两条缺一不可。

ε-δ 视角下的传递

拖动 ε 滑块，可以看到邻域带实时变化： 外函数图中紫色横带 $y\in(L-\varepsilon,L+\varepsilon)$ 对应青色竖带 $u\in(u_0-\delta_u,u_0+\delta_u)$； 再回到内函数图，该青色横带对应靛蓝竖带 $|x-x_0|<\delta_x$。 两个 δ 一层层向前传递，这正是法则的证明思路。 若在某个环节上邻域内出现无定义的点，传递就断了。

小结

  • 复合函数求极限 = 先求内层极限，再代入外层极限：$\lim f(g(x))=\lim_{u\to u_0}f(u)$。
  • 适用三前提：内层极限存在 + 外层极限存在 + 存在去心邻域使 $f(g(x))$ 有定义且 $g(x)\neq u_0$。
  • 若外函数 $f$ 在 $u_0$ 处连续，则 $g(x)\neq u_0$ 可省，但“去心邻域有定义”仍不可省。
  • 仅 $x_0$ 是 $D_g$ 聚点、$u_0$ 是 $D_f$ 聚点，不足以保证复合函数在去心邻域内有定义（案例 B、C）。
  • 内层函数值落在外函数定义域之外时，复合函数无定义，极限不存在。
  • 内层极限不存在（如振荡）时，整个法则失效，需另想办法。
